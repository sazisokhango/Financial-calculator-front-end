# Implementation Plan: Investment Forecast

**Branch**: `feature/007-investment-forecast` | **Date**: 2026-05-21 | **Spec**: [spec.md](spec.md)

---

## Summary

Add an Investment Forecast feature to the existing Angular 21 financial calculator. The dashboard gains tab navigation (`?tab=tax` | `?tab=investments`) driven by Angular Router query params. Three new standalone components handle the full CRUD flow (new forecast form, view result page with monthly projection table, edit form). A new `InvestmentService` wraps the five `/api/investments` endpoints. Two new TypeScript model interfaces are added; no existing models are changed.

---

## Technical Context

**Language/Version**: TypeScript 5.x / Angular 21

**Primary Dependencies**: `FormBuilder`, `Validators`, `ReactiveFormsModule`, `forkJoin`, `ActivatedRoute`, `Router`, `queryParams`, Angular Signals, new `InvestmentService`; existing `UserService`

**Storage**: None (backend owns persistence)

**Testing**: Angular TestBed + Jasmine; one SpecKit spec file per new component and service

**Target Platform**: Web browser (SPA at `localhost:4200` in development)

**Constraints**: `apiBaseUrl` from `environment` only; `@for`/`@if` control flow; Tailwind CSS v4 only; no component libraries; standalone components only

**Scale/Scope**: Adds 3 new components, 1 new service, 2 new models, modifies 2 existing files (`DashboardComponent`, `app.routes.ts`)

## Implementation Phases

### Phase 1 — Models

1. Create `investment-forecast.model.ts` — `MonthlyProjection` and `InvestmentForecast` interfaces
2. Create `investment-forecast-request.model.ts` — `InvestmentForecastRequest` interface

### Phase 2 — Service

3. Create `investment.service.ts` with five methods:
   - `getAllByUser(userId: number)` → `GET /api/investments?userId={userId}`
   - `getById(id: number)` → `GET /api/investments/{id}`
   - `create(payload: InvestmentForecastRequest)` → `POST /api/investments/forecast`
   - `update(id: number, payload: InvestmentForecastRequest)` → `PUT /api/investments/{id}`
   - `delete(id: number)` → `DELETE /api/investments/{id}`
   - All methods use `catchError → throwError` with `err.error?.message` fallback
4. Create `investment.service.spec.ts`

### Phase 3 — Routes

5. Add three routes to `app.routes.ts`:
   - `user/:id/investments/forecast` → `InvestmentForecastComponent`
   - `user/:id/investments/:forecastId` → `ViewInvestmentComponent`
   - `user/:id/investments/:forecastId/edit` → `EditInvestmentComponent`

### Phase 4 — Dashboard Tab Navigation

6. Modify `dashboard.component.ts`:
   - Add `forecasts = signal<InvestmentForecast[]>([])`
   - Add `activeTab = signal<'tax' | 'investments'>('tax')`
   - Add `forecastsLoading = signal(false)` and `forecastsError = signal<string | null>(null)`
   - Subscribe to `ActivatedRoute.queryParams` to update `activeTab` signal
   - Extend `forkJoin` to include `investmentService.getAllByUser(userId)` alongside user and tax calls
   - Add `newForecast()`, `viewForecast(id)`, `deleteForecast(id)` methods
7. Modify `dashboard.component.html`:
   - Replace current header "New Calculation" button with conditional button based on active tab
   - Add tab bar below header: "Tax Calculator" tab and "Investment Forecast" tab using `[routerLink]` + `[queryParams]`
   - Wrap existing calculations list in `@if (activeTab() === 'tax')`
   - Add `@if (activeTab() === 'investments')` section with investment forecast cards (same card layout as tax) showing title, description, date, delete icon, and final projected value pill

### Phase 5 — Investment Forecast Form (New)

8. Create `investment-forecast.component.ts`:
   - `FormBuilder.group` with 6 controls and validators from data-model
   - On init: read `:id` from route params
   - `onSubmit()`: build `InvestmentForecastRequest` with `userId` from route; call `investmentService.create()`; navigate to `/user/:id/investments/:forecastId` on success
   - `submitting` signal for button loading state
9. Create `investment-forecast.component.html`:
   - Header: "New Investment Forecast" + "Back" link to `/user/:id?tab=investments`
   - Form with 6 fields; inline validation error below each affected field
   - "Calculate Forecast" button with spinner during `submitting()`

### Phase 6 — View Investment Result

10. Create `view-investment.component.ts`:
    - On init: read `:id` and `:forecastId` from route params; call `investmentService.getById(forecastId)`
    - Signals: `forecast`, `loading`, `error`
    - `edit()` navigates to `/user/:id/investments/:forecastId/edit`
    - `back()` navigates to `/user/:id?tab=investments`
    - `deleteForecast()`: confirm dialog → `investmentService.delete(forecastId)` → navigate to `/user/:id?tab=investments`
11. Create `view-investment.component.html`:
    - Inputs section: all 6 input fields labelled and formatted
    - Forecast summary section: 5 summary fields, monetary values formatted with `CurrencyPipe` (`ZAR`, `en-ZA`)
    - Monthly projection table: `@for (row of forecast()!.monthlyProjections; track row.month)` with 5 columns, monetary values formatted
    - Action buttons: "Back", "Edit", "Delete"

### Phase 7 — Edit Investment Form

12. Create `edit-investment.component.ts`:
    - Same `FormBuilder.group` as `InvestmentForecastComponent`
    - On init: `forkJoin` of `investmentService.getById(forecastId)` + resolve `userId` from route; `form.patchValue()` with existing values
    - `onSubmit()`: call `investmentService.update(forecastId, payload)`; navigate to view page on success
    - `cancel()` navigates back to `/user/:id/investments/:forecastId`
13. Create `edit-investment.component.html`:
    - Identical layout to new forecast form; header reads "Edit Investment Forecast"; submit button reads "Save Changes"
    - "Cancel" link navigates to view page

### Phase 8 — Spec Files

14. Create `investment-forecast.component.spec.ts`
15. Create `view-investment.component.spec.ts`
16. Create `edit-investment.component.spec.ts`
