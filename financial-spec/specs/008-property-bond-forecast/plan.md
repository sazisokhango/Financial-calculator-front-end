# Implementation Plan: Property Bond Forecast

**Input**: Feature specification from `/specs/008-property-bond-forecast/spec.md`

## Summary

Add a Property Bond Forecast feature to the existing Angular 21 financial calculator. The dashboard gains a third tab (`?tab=bonds`) alongside the existing Tax Calculator and Investment Forecast tabs. The dashboard data loading strategy is changed from a flat `forkJoin([user$, tax$, investments$])` to a `switchMap`-chained load (user first, then tax + investments + bonds in parallel) because bond data requires `userEmail` from the loaded `User` object. Three new standalone components handle the full CRUD flow (new bond form, view result page with monthly repayment table, edit form). A new `BondService` wraps the five `/api/bonds` endpoints. Two new TypeScript model files are added; two existing files (`DashboardComponent`, `app.routes.ts`) are modified.

## Implementation Phases

### Phase 1 — Models

1. Create `property-bond.model.ts` — `BondMonthlyProjection`, `BondForecastResult`, `PropertyBond` interfaces
2. Create `property-bond-request.model.ts` — `PropertyBondRequest` interface

### Phase 2 — Service

3. Create `bond.service.ts` with five methods:
   - `getAllByUser(userEmail: string)` → `GET /api/bonds?userEmail={email}`
   - `getById(id: number)` → `GET /api/bonds/{id}`
   - `create(payload: PropertyBondRequest)` → `POST /api/bonds`
   - `update(id: number, payload: PropertyBondRequest)` → `PUT /api/bonds/{id}`
   - `delete(id: number)` → `DELETE /api/bonds/{id}`
   - All use `catchError → throwError` with `err.error?.message` fallback
4. Create `bond.service.spec.ts`

### Phase 3 — Dashboard Modification

5. Modify `dashboard.component.ts`:
   - Inject `BondService`; add `switchMap` import
   - Extend `activeTab` signal type to `'tax' | 'investments' | 'bonds'`
   - Update `queryParams` subscription to handle `'bonds'`
   - Add `bonds = signal<PropertyBond[]>([])` and `bondsError = signal<string|null>(null)`
   - Replace flat `forkJoin` with `userService.getById().pipe(switchMap(user => forkJoin([tax$, investments$, bonds$])))` (see research.md — Decision 2)
   - Add `newBondForecast()` and `deleteBond(id)` methods

6. Modify `dashboard.component.html`:
   - Add third tab link for `?tab=bonds`
   - Extend header button conditional for `activeTab() === 'bonds'`
   - Add bond cards section under `@if (activeTab() === 'bonds')`

### Phase 4 — Bond Forecast Form (New)

7. Create `bond-forecast.component.ts`:
   - `FormBuilder.group` with 6 controls and validators per data-model.md
   - Loads `userEmail` via `userService.getById(userId)` on init (stored in signal, not a form field)
   - `onSubmit()` builds `PropertyBondRequest` with `userEmail()` signal; navigates to view page on success

8. Create `bond-forecast.component.html`:
   - Header + Back link to `?tab=bonds`
   - 6-field form with per-field inline validation errors
   - "Calculate Bond Forecast" button with loading state

### Phase 5 — View Bond Result

9. Create `view-bond.component.ts`:
   - Loads bond via `bondService.getById(bondId)` on init
   - `edit()`, `back()`, `deleteBond()` methods

10. Create `view-bond.component.html`:
    - Inputs section, forecast summary section, 6-column monthly repayment table
    - All monetary values via `CurrencyPipe 'ZAR':'symbol':'1.2-2'`
    - `fullyPaid` rendered as "Yes" / "No"

### Phase 6 — Edit Bond Form

11. Create `edit-bond.component.ts`:
    - `forkJoin([bondService.getById(bondId), userService.getById(userId)])` on init
    - `form.patchValue()` with existing bond values
    - `onSubmit()` calls `bondService.update()`

12. Create `edit-bond.component.html`:
    - Identical layout to new forecast form; header "Edit Bond Forecast"; submit "Save Changes"

### Phase 7 — Route Registration

13. Add to `app.routes.ts`:
    ```typescript
    { path: 'user/:id/bonds/forecast', component: BondForecastComponent },
    { path: 'user/:id/bonds/:bondId', component: ViewBondComponent },
    { path: 'user/:id/bonds/:bondId/edit', component: EditBondComponent }
    ```
    ⚠️ Static `bonds/forecast` must appear before dynamic `bonds/:bondId`.

### Phase 8 — Spec Files

14. Create `bond-forecast.component.spec.ts`
15. Create `view-bond.component.spec.ts`
16. Create `edit-bond.component.spec.ts`
